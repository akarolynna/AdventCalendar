## ✨ Sobre o projeto 

O Calendário do Advento é um convite para viver os 24 dias que antecedem o Natal de uma maneira especial, dedicando um momento de cada dia à Palavra de Deus e à reflexão sobre o verdadeiro significado dessa celebração: o nascimento de Jesus.

A cada portinha, uma nova mensagem é revelada, acompanhada de um versículo bíblico, uma reflexão e um convite para colocar a fé em prática no dia a dia. São pequenos momentos que nos ajudam a desacelerar, olhar para o que realmente importa e preparar o coração para o Natal.

Mais do que contar os dias para essa celebração, o propósito é viver cada um deles com fé, esperança e intencionalidade. Que, a cada mensagem descoberta, Cristo encontre mais espaço em nosso coração e que a luz do Seu nascimento ilumine nossos dias.

## 🎁 Funcionalidades

- **Calendário interativo:** 24 portinhas que representam os dias de preparação para o Natal.
- **Mensagens diárias:** versículos bíblicos e reflexões para cada dia do Advento.
- **Abertura das portinhas:** interação visual para revelar o conteúdo de cada data.
- **Liberação por data:** acesso às mensagens conforme o avanço do calendário.
- **Design responsivo:** experiência adaptada para computadores, tablets e celulares.
- **Experiência natalina:** interface temática com elementos visuais inspirados no Natal e na mensagem cristã.

## 🎨 Identidade visual

A interface foi pensada para transmitir a alegria e o acolhimento do Natal por meio de uma composição visual leve e festiva.

- **Verde:** esperança, vida e renovação.
- **Vermelho:** calor, amor e celebração.
- **Creme e dourado:** equilíbrio, delicadeza e os detalhes luminosos da identidade natalina.

A proposta é unir uma experiência digital interativa a uma mensagem de fé, mantendo a navegação intuitiva e o conteúdo como protagonista.

## 🚀 Como executar o projeto

Para executar o Calendário do Advento localmente, siga os passos abaixo.

**1. Clone o repositório**

```bash
git clone https://github.com/akarolynna/AdventCalendar.git
```

**2. Acesse a pasta do projeto**

```bash
cd AdventCalendar
```

**3. Execute o projeto**

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no Visual Studio Code para iniciar um servidor local e visualizar o site.
